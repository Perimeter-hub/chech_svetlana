# 🇨🇿 Čeština pro Světlanu

Интерактивное приложение для изучения чешского языка с нуля.  
Разработано специально для Светланы — пенсионерки, живущей в Праге.

## 👩‍🏫 Персонажи

- **Лючия** — учительница, носитель чешского языка, 45–55 лет
- **Ольга** — подруга по учёбе, уровень A2 (пример для Светланы)
- **Светлана** — ученица, начинает с нуля (A1)

## ✨ Возможности приложения

- 💬 **Диалоги** — каждый урок содержит диалог Светланы с Лючией
- 👩 **Параллельный диалог Ольги (A2)** — пример более свободной речи
- 🔊 **Регулировка скорости** — 0.8× / 0.85× / 1× для каждой реплики Лючии
- 📖 **Слова урока** — карточки с транскрипцией, нажмите → услышите
- ✏️ **Задания** — лёгкие вопросы с обратной связью
- 📊 **Прогресс** — сохраняется автоматически
- 🎤 **Запись голоса** *(v2)* — записывайте своё произношение
- 🎧 **Сравнение** *(v2)* — кнопки «▶ Лючия» и «▶ Я» рядом

---

## 📱 Как установить на Android

1. Откройте ссылку на версию в браузере Chrome
2. Нажмите меню **⋮ → Добавить на главный экран**
3. Приложение работает как нативное!

Или используйте [PWABuilder](https://www.pwabuilder.com) / [WebIntoApp](https://webintoapp.com) для создания APK.
